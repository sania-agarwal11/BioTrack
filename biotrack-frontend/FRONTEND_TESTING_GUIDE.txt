================================================================================
  COMMON ERRORS & FIXES
================================================================================

ERROR: "Invalid email or password" on login
FIX  : Check user exists in DB. Register via IAM Swagger if needed.

ERROR: Table shows empty after login
FIX  : Check backend service is running. Check gateway port 8778 is up.
       Check browser console for 500/404 errors.

ERROR: 403 Forbidden on all requests after login
FIX  : Token may be expired (1 hour). Log out and log in again.

ERROR: Audit Logs always empty
FIX  : Run SQL: ALTER TABLE biotrack_compliance.audit_logs
              MODIFY COLUMN user_id BIGINT NULL;
       Then restart compliance-service.

ERROR: Sites by Protocol returns empty
FIX  : Make sure you've done POST /api/v1/protocols/{id}/sites/{siteId}
       (Assign Site button in Protocols page) BEFORE filtering.

ERROR: Cannot connect to backend (Network Error)
FIX  : Ensure gateway is running on port 8778.
       Ensure frontend vite proxy is running (npm run dev).
       Check vite.config.js proxy target is http://localhost:8778

ERROR: Page redirects to /dashboard after typing URL
FIX  : Your current role doesn't have access to that page.
       This is correct security behavior. Login with appropriate role.

ERROR: Modal doesn't close after save
FIX  : Backend returned an error — check the red alert box inside the modal.

ERROR: "Failed to save" with no details
FIX  : Check browser DevTools → Network tab → find the failed request
       and check the response body for the error message.
